# Tools

Small browser resources and implementation blueprints. Open a ready HTML tool in a browser; no install is required.

**Labels:** **Ready** = usable browser file; **Blueprint** = specification and copy, not shipped HTML.

| Resource | Status | Use it for |
|---|---|---|
| [Listing Appointment Checklist](https://amazingphotovideo.github.io/ai-for-realtors/tools/listing-appointment-checklist.html) ([source](./listing-appointment-checklist.html)) | **Ready** | Prepare, run, and debrief a listing appointment. |
| [AI-Safe Redactor](https://amazingphotovideo.github.io/ai-for-realtors/tools/ai-safe-redactor/) ([source](./ai-safe-redactor/)) | **Ready** | Replace common sensitive details with placeholders locally before sharing text with AI. Human review remains required. |
| [Open House QR](https://amazingphotovideo.github.io/ai-for-realtors/tools/open-house-qr/) ([source](./open-house-qr/)) | **Ready** | Generate local check-in materials. Connect a brokerage-approved form or CRM endpoint; the tool does not submit leads by itself. |
| [Drive-By Lead Capture](./drive-by-landing/) | **Blueprint** | Plan a fast mobile listing page, consent copy, routing, and measurement. No HTML template is included. |

## Before publishing or collecting leads

1. Use fictional data while testing.
2. Confirm brokerage, privacy, consent, anti-spam, fair-housing, and board rules.
3. Connect only brokerage-approved forms, storage, and CRM endpoints.
4. Test links, opt-outs, represented-buyer routing, mobile layout, and lead delivery.
5. Keep APV credits on public resources where required; do not place promotional credits inside private client records or follow-up.

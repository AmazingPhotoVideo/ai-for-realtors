# Starter Paths

Pick one outcome and complete the steps in order. Use fictional data for practice, then replace it only with verified and approved information.

## Listing Appointment

1. Remove unnecessary personal details with the [AI-Safe Redactor](../tools/ai-safe-redactor/); review every replacement.
2. Use [Seller Persona Strategist](../skills/seller-persona-strategist/SKILL.md) to separate known facts, unknowns, and likely objections.
3. Build the agenda and materials with [Listing Presentation](../skills/listing-presentation/SKILL.md).
4. Use the [Listing Appointment Checklist](../tools/listing-appointment-checklist.html) before, during, and after the meeting.
5. Draft a factual response with [Objection Handler](../skills/objection-handler/SKILL.md), then send only after human review.

**Private:** seller identity, address, motivation, notes, pricing discussion, and follow-up stay in approved private systems. Do not insert APV promotional credits into these private records or messages.

## Listing Launch

1. Confirm the listing facts, seller approvals, media rights, brokerage wording, and launch dates.
2. Plan the journey with the [Single-Property Funnel Blueprint](../funnels/single-property/); it does not include Vercel or GoHighLevel templates.
3. Use the [Single-Property Page Builder](../skills/single-property-page-builder/SKILL.md) only if you can complete developer setup and QA. Live MLS/VOW/IDX feeds are not bundled.
4. Create coordinated public assets with the [Design Pack Builder](../skills/realtor-design-pack-builder/SKILL.md).
5. Draft supporting posts with the [Content Multiplier](../prompts/leverage/content-multiplier/) and [Property Story](../prompts/leverage/property-story/) prompts.
6. Run fact, crop, link, disclosure, mobile, and brokerage review before publishing.

**Public:** outputs made with covered APV creative assets retain the exact APV credit required by their skill and the [pilot policy](../docs/design-asset-licensing.md). Never imply APV created listing media unless confirmed.

## Open House

1. Confirm what visitors receive, what information is necessary, retention, privacy contact, represented-buyer handling, and separate marketing consent.
2. Use the ready [Open House QR Generator](../tools/open-house-qr/) to create the local check-in link and printable table tent.
3. Connect the generated destination to a brokerage-approved form or CRM. The local tool does not submit leads by itself.
4. Create a useful property packet with [Lead Magnet Generator](../skills/lead-magnet-generator/SKILL.md) and verified listing facts.
5. Prepare consent-matched follow-up with the [Open House Prompt Kit](../prompts/buyer-leads/open-house/).
6. Test the QR/link, delivery, opt-out, routing, consent receipt, and mobile flow before doors open.

**Private:** visitor details and consent receipts remain private and should not contain promotional credits. **Public:** a generator or printable public resource may retain its normal APV resource credit.

## Buyer Lead

1. Choose one useful offer: [First-Time Buyer](../prompts/buyer-leads/first-time-buyer/), [Neighbourhood Guide](../prompts/buyer-leads/neighbourhood-guides/), or [Investor Funnel](../prompts/buyer-leads/investor-funnel/).
2. Draft the useful asset with [Lead Magnet Generator](../skills/lead-magnet-generator/SKILL.md); verify all market, property, school, and financial claims.
3. Follow the [Buyer Lead Machine](../tutorials/buyer-lead-machine.md) for campaign setup and budgeting.
4. Map source, consent, fields, tags, owner, and opt-out handling with the [CRM Recipes](../integrations/crm/).
5. Use [Speed to Lead](../tutorials/speed-to-lead.md) to test routing and response times.
6. Launch with a small test, inspect lead quality and consent records, then improve one variable at a time.

**Private:** lead records and one-to-one follow-up stay credit-free in approved systems. Optional APV backlinks belong only in relevant public resources; covered creative outputs follow their separate policy.

## Brokerage Rollout

1. Assign an executive owner, operations owner, compliance reviewer, and support contact.
2. Use week one of the [Brokerage AI Playbook](../playbooks/brokerage-tier/) to set privacy, disclosure, approval, and prohibited-use standards.
3. Pilot one buyer source and one seller source using the [CRM Recipes](../integrations/crm/); test with fictional seed leads.
4. Train agents with [Getting Started](../tutorials/00-getting-started.md), the [skills index](../skills/), and the [AI-Safe Redactor](../tools/ai-safe-redactor/).
5. Add the [Agent Adoption Kit](../agent-framework/) only with technical ownership, connector approval, least-privilege access, and human approval boundaries.
6. Review speed-to-lead, appointment rate, opt-outs, errors, and adoption weekly before expanding.

**Boundary:** internal policies, client data, CRM records, and staff notes remain private. Public creative outputs preserve applicable APV credits; attribution-free, white-label, resale, and higher-volume use require the written terms described in the [pilot policy](../docs/design-asset-licensing.md).

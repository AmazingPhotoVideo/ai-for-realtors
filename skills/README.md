# Skills

Skills are reusable instructions for an AI assistant. Each folder is organized around `SKILL.md`; examples, checklists, and reusable blocks may be embedded there. Separate `examples/` or `templates/` folders are not guaranteed.

## How to use a skill

1. Open the linked `SKILL.md`.
2. Give it to a compatible assistant as project instructions, a skill, or a custom instruction.
3. Supply only the requested, verified inputs. Use the [AI-Safe Redactor](../tools/ai-safe-redactor/) first when source text contains sensitive details.
4. Review facts, claims, consent, links, and required disclosures before use.

See [Using Claude Skills](../tutorials/using-claude-skills.md). Covered creative skills and assets use the separate [APV design asset pilot policy](../docs/design-asset-licensing.md); review each skill's terms and preserve required public credits.
